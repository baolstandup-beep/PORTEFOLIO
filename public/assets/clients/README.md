# Logos clients

Déposez ici les fichiers individuels approuvés par les marques (SVG, WebP, PNG ou JPEG).
Dans `assets/client-logos.js`, remplacez le champ `logo: ''` de chaque client par un chemin comme `assets/clients/bkk.svg`.
Le nom typographique reste visible tant qu'aucun fichier n'est renseigné, ou si le fichier est introuvable.
Ajoutez ou retirez une entrée du tableau `clients` pour modifier le bandeau ; la duplication nécessaire à l'animation est automatique.

L'ancienne affiche multimarque fournie sert de référence uniquement ; elle n'est ni affichée ni découpée en logos.
